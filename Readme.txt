Website Structure:
- index.html: Home page introducing Student Bites.
- restaurants.html: Shows six student-friendly restaurants.
- recommend.html: Lets the user choose preferences and receive a restaurant recommendation.
- register.html: Registration form with JavaScript validation.
- reservation.html: Reservation form with deposit and payment logic.
- bill.html: Optional bonus estimated bill calculator page.
- css/style.css: External CSS used by all pages.
- js/script.js: External JavaScript used by all pages.
- images/: Stores all website images.

JavaScript Validation Logic:
The registration form checks username, email, phone number, password strength, confirm password, gender, dietary preference, and country/region. If there are errors, they are displayed on the page and the form does not submit.

The reservation form checks full name, email, phone number, reservation date/time, number of people, billing email, and card details if online payment is selected. Voucher payment shows the voucher field and hides card fields. Online payment shows card fields and hides the voucher field. Restaurant deposits update automatically when the selected restaurant changes.

Recommendation Logic:
The recommendation page uses simple if/else rules. Vegan users get Green Bowl Co., halal users get Halal Hub, high budget or date users get Seoul Student BBQ, friends get Slice Society, business users get Noodle Nest, and other users get Campus Grill.

Known Issues or Limitations:
- The website is front-end only and does not use a real database.
- Credit card validation only checks digit length as required by the assignment.
- Images are sample assignment images and should be replaced or referenced properly if third-party images are used.
